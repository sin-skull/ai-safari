# Safari改修の方針

対象は **iPhone 17 の Safari**。必要なファイルの初回取得後は、機内モードで自然な日本語会話を続けられることを基礎目標にする。その後、コード生成・修正、会話からのWebアプリ開発へ進む。オフラインの音声会話も実現し、声でも開発や操作を行えるアシスタントを目指す。専用iPhoneアプリやクラウド推論への移行を前提にしない。最新の段階と合格条件は [ロードマップ](ROADMAP.md) にまとめる。

## 保存先

同じGitHub Pagesドメインでは、リポジトリのURLパスが違っても保存領域は同じオリジンに属する。以下を専用の名前にした。

| 用途 | ai-safari |
| --- | --- |
| IndexedDB | `ai-safari` |
| アプリキャッシュ | `ai-safari-app-<version>` |
| Transformers.js本体 | `ai-safari-lib-1` |
| Transformers.jsモデル・WASM | `ai-safari-transformers-cache` |
| 正常終了の目印 | `ai-safari-closed-normally` |
| 試験室の記録 | `ai-safari-lab-step` / `ai-safari-lab-history` |
| 試験室モデルのOPFSフォルダ | `ai-safari-lab-cache` |

コピー先で元のDBを自動的に開いたり、元のキャッシュを削除したりしない。記憶を移す場合は元のアプリで書き出し、コピー先で明示的に読み込む。バックアップ形式 `ai-backup` は互換性のため変更しない。モデルはコピー先で改めて取得する。

## 開発順序と現在の進捗

2〜4の文字会話の基盤を先に実装した。次は実際の失敗例を使い、モデル・プロンプト・履歴・実行処理を切り分けて評価する。iPhone実機で1の測定も行い、品質と安定性の両方で採用を判断する。以下の5〜8は自然言語会話の合格後に着手する。コード生成に音声対応の完成は必須とせず、7 → 8を独立した開発経路にする。

1. labで小型モデルのCPU/GPU実行を比べ、iPhone 17 Safariで日本語の会話品質と待ち時間を測る。読み込み成功だけで採用しない。
2. 回答、検索、索引作成の実行とモデルの解放を一か所で管理する。重い処理を重ねない。起動時のクラッシュを繰り返さない。
3. 資料がなくても雑談・相談に答え、前の発言を踏まえる会話を実装する。直近の会話と保存する記憶を分ける。
4. スマホ用/PC用のモデルと負荷設定を切り替えられるようにする。会話・記憶の形式は共通にする。
5. オフライン日本語音声認識を単独で検証する。標準のブラウザ音声認識が使えるだけではオフライン対応としない。
6. 端末内の読み上げと接続し、最初は画面を開いてボタンを押して話す形式を完成させる。その後、話し終わり検出と読み上げ停止・割り込みを検証する。
7. コード生成・修正を実装する。最初はHTML・CSS・JavaScriptを対象に、自然言語の依頼から生成・実行・確認・修正・保存までを端末内で行う（ロードマップのフェーズ10）。
8. アプリ開発を実装する。仕様の相談、複数ファイルの管理、プレビュー、動作確認、不具合修正、書き出し・再開までをつなぐ。まず小さなWebアプリで完成を検証する（フェーズ11）。

## 確認基準

- 元とコピー先を同時に使っても、知識・モデル削除・キャッシュ更新が互いに干渉しない。
- iPhone 17 Safariで、必要なファイルを保存した後に機内モードで再起動できる。
- 雑談、続きの質問、訂正、保存した記憶を含む会話を数分続けられる。
- 待ち時間、連続処理、再起動、発熱を記録する。実機未検証の項目を「確認済み」と書かない。
- 音声入力・会話・読み上げの一連の処理が通信なしで動く。
- 自然言語の依頼に沿うコードを生成し、実行結果を確認して修正できる。未実行のものは確認済みとしない。
- 小さなWebアプリを会話から完成させ、保存・再起動後も利用と開発を再開できる。PCだけで動く状態をiPhone対応済みとしない。

## 新会話画面の保存先

- モデル: OPFS `ai-safari-conversation-models`（試験室とは別）。
- 会話履歴・下書き: IndexedDB `ai-safari` の settings / `conversation-thread-v2:<id>`。選択中の会話は `conversation-active-v2`。旧 `conversation-v1` は初回に移行する。
- 端末設定・動作記録: localStorage `ai-safari-conversation-*`。動作記録に会話本文は含めない。
- `memory.html`は記憶管理専用として旧回答モデル・意味検索モデルを起動しない。会話画面・試験室の複数タブのモデル保持はWeb Locksで排他する。
